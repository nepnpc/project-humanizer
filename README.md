# Project Humanizer

Makes AI-generated text sound human. Live API.

FastAPI wrapping Groq Llama 3 + spaCy. Validates input, batches text, returns clean JSON. No babysitting required.

## Stack
- FastAPI
- Groq Llama 3
- spaCy

## API
`POST /humanize` — pass text, get human-sounding output back.
